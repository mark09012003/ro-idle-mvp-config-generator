# 神工匠批次精練

這是獨立的 Chrome 擴充功能。到 `chrome://extensions` 開啟開發人員模式，按「載入未封裝項目」並選取本資料夾。

1. 登入 RO 放置仙境，停止欲使用的神工匠角色掛機。
2. 在遊戲分頁開啟擴充功能，選擇神工匠並勾選背包武器。
3. 檢查材料與 SP，確認後執行。執行期間保持擴充功能視窗開啟。

只使用神工匠的「武器精練」，每次提升一級。上限為武器的基礎安全值與技能等級的較低者。已裝備、上鎖、未鑑定或損壞的武器會略過。停止批次會等待正在送出的那一步完成。連線或狀態異常時，先重新讀取背包確認結果再操作。

武器與安全精練材料表取自 [RO 放置仙境公開客戶端內容包](https://ro-idle.app/source/ro-idle-client-src-407a0ccd5.tar.gz)。
