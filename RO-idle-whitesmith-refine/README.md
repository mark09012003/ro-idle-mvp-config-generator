# 神工匠批次精練

這是獨立的 Chrome 擴充功能。到 `chrome://extensions` 開啟開發人員模式，按「載入未封裝項目」並選取本資料夾。若已安裝，更新資料夾後在擴充功能頁按重新載入。

1. 登入 RO 放置仙境，停止欲使用的神工匠角色掛機。
2. 在遊戲分頁開啟擴充功能，選擇神工匠和精練目標。預設各武器精練到 100% 成功的上限，也可以指定 +1 至技能等級（最高 +10）。
3. 勾選武器。開啟「從倉庫挑選武器並補足材料」後，可同時選取倉庫武器，材料會先用背包存量，再從倉庫取出差額。取出時角色須在有卡普拉服務的城鎮，並有足夠的 Zeny、負重及空間。
4. 確認武器、材料、倉庫費及精練風險後執行。期間請保持擴充功能視窗開啟。

只使用神工匠的「武器精練」。已裝備、上鎖、未鑑定或損壞的武器會略過。成功以武器達到目標為準，失敗以武器精練失敗消失為準。失敗的武器及已插入的卡片會消失，批次會繼續處理下一件。手動停止會等待已送出的操作完成，連線或狀態異常則會停止並列出待確認件數。

武器、成功率及材料資料取自 [RO 放置仙境公開客戶端內容包](https://ro-idle.app/source/ro-idle-client-src-407a0ccd5.tar.gz)。
