# 批次裝備精練

到 `chrome://extensions` 開啟開發人員模式，按「載入未封裝項目」並選取本資料夾。已安裝的話，更新資料夾後在擴充功能頁按重新載入。

1. 登入 RO 放置仙境，進入要使用的角色並停止掛機。在該分頁開啟擴充功能，即可使用目前角色。
2. 選擇精練方式及目標。學會武器精練的神工匠預設使用技能，也可以切換城鎮精練。城鎮精練適用於武器與防具，任何職業可用。未穿戴的裝備只能一鍵精練至安全值；已穿戴的裝備可指定等級。
3. 要精練未穿戴的防具到其他等級，可勾選「自動穿戴防具後精練，完成後換回原裝」。每件完成或停止後會還原裝備欄，執行中請保持擴充視窗開啟。若還原未獲確認，請檢查裝備欄。
4. 可依裝備名稱、道具 ID 或來源篩選。全選只套用目前顯示的裝備，篩選前勾選的裝備仍會保留。可單獨開啟「從倉庫補足材料」，只取出背包不足的材料，也可另外勾選「從倉庫挑選裝備」。取出時角色須在有卡普拉服務的城鎮，並有足夠的 Zeny、負重及空間。
5. 確認裝備、材料、費用及精練風險後執行。期間請保持擴充功能視窗開啟。

已上鎖、未鑑定或損壞的裝備會略過。成功以裝備達到目標為準，失敗以裝備精練失敗消失為準。失敗的裝備及已插入的卡片會消失，批次會繼續處理下一件。手動停止會等待已送出的操作完成，連線或狀態異常則會停止並列出待確認件數。

裝備、成功率、材料及精練師地點取自 [RO 放置仙境公開客戶端內容包](https://ro-idle.app/source/ro-idle-client-src-407a0ccd5.tar.gz)。

## 攤位限價購買

展開「攤位搜尋與限價購買」，填入裝備名稱、指定洞數、單價上限及最多購買件數，按「搜尋並預覽」。洞數是裝備原本的插卡槽數。結果會列出其他城鎮的商品及位置，到當地後再搜尋即可購買。確認後會依單價由低到高購買目前城鎮的預覽商品。若價格、商品或可購買數量變動，須重新預覽。每次執行只購買這一批。

## 弓箭手自動加點與轉生

在已進入角色的遊戲分頁打開擴充，展開「弓箭手自動加點與轉生」，按「啟用流程」。此功能只在目前遊戲分頁運作，關閉或重新整理分頁後須重新啟用。擴充視窗可收起。流程會偵測角色畫面的等級變化，另每分鐘確認一次角色狀態。

- 初學者完成基本技能 9、緊急治療 1，再轉弓箭手。進階初學者轉進階弓箭手。
- 弓箭手依序點二連矢 5、箭雨 10、鶚梟之眼 10、蒼鷹之眼 1、心神凝聚 10、蒼鷹之眼 10、二連矢 9，花完一轉 49 點再轉獵人或神射手。
- 獵人依可學的二轉技能補滿 49 點。神射手先點銳射 5、動物殺手 1、馴鷹術 1、狙殺瞄準 10，Base 75 後點風之步 10，再補滿 69 點。
- 技能一次送出當前可分配的一整批。達成遊戲要求後轉生，每次需 1,285,000 Zeny。第 10 次轉生後達 Base 99／Job 70，只結束自動加點與轉職流程，掛機照常。

擴充只送出學技能、轉職與轉生指令。遊戲本身在轉生時會停用掛機技能規則和自動屬性配點。已有的練功腳本可以繼續使用。

## 跨角色換裝重綁

搬裝備前，在原角色開啟「跨角色換裝重綁」，按「記錄原角色裝備」。再讓新角色取出裝備、匯入原掛機設定，按「預覽目前角色」。當換裝規則與備份相同時，擴充會比對道具、精練、卡片及鍛造資料，只預選唯一配對。已經搬完且沒有對照時，可以按舊 UID 逐項選擇新裝備。確認套用後，同一個舊 UID 在所有換裝規則裡會一起更新。

## 神射11轉裝備交接

原角色停止掛機、進入有卡普拉服務的城鎮，按「記錄並存倉」。擴充從已儲存的「神射11轉」讀取換裝規則，將穿戴和規則引用的裝備整批存倉，並記下倉庫編號。箭矢留在原角色，新角色需自行準備配置所用的箭矢。

切換到同帳號的新角色，在卡普拉城鎮按「領裝並套用配置」，領取後會重綁 UID 並建立同名配置。已有同名配置時會在確認畫面提示覆蓋。未轉生的角色會略過「Base Lv 至少 64」的主手換裝，該條其餘部位仍保留。成功前請保持擴充視窗開啟。存取結果不明時，先檢查實際背包及倉庫，再清除本機交接紀錄。

「角色練功」的轉生計時依角色儲存在本機。會記錄觀測到的轉生、轉職、神射手 Base 75、風之步 10、Base 99 和 Job 滿級時間。由轉生開始的完整紀錄以兩次轉生之間的實際經過時間計算，第 10 轉則以達成 Base 99／Job 70 結算。中途啟用或錯過轉生時間的輪次會標示為部分紀錄。
