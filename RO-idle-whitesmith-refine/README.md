# 批次裝備精練

到 `chrome://extensions` 開啟開發人員模式，按「載入未封裝項目」並選取本資料夾。已安裝的話，更新資料夾後在擴充功能頁按重新載入。

1. 登入 RO 放置仙境，進入要使用的角色並停止掛機。在該分頁開啟擴充功能，即可使用目前角色。
2. 選擇裝備類型及精練目標。武器使用神工匠的武器精練技能。防具使用城鎮精練師，任何職業可用。背包或倉庫中未穿戴的防具只能一鍵精練至安全值；已穿戴的防具可指定等級。
3. 勾選裝備。可單獨開啟「從倉庫補足材料」，只取出背包不足的材料，也可另外勾選「從倉庫挑選裝備」。取出時角色須在有卡普拉服務的城鎮，並有足夠的 Zeny、負重及空間。
4. 確認裝備、材料、費用及精練風險後執行。期間請保持擴充功能視窗開啟。

已上鎖、未鑑定或損壞的裝備會略過。成功以裝備達到目標為準，失敗以裝備精練失敗消失為準。失敗的裝備及已插入的卡片會消失，批次會繼續處理下一件。手動停止會等待已送出的操作完成，連線或狀態異常則會停止並列出待確認件數。

裝備、成功率、材料及精練師地點取自 [RO 放置仙境公開客戶端內容包](https://ro-idle.app/source/ro-idle-client-src-407a0ccd5.tar.gz)。
