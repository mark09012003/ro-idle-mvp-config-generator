# RO 放置仙境 · 單怪 DPS 試算

這是獨立的 Chrome 擴充。到 `chrome://extensions` 開啟「開發人員模式」，選「載入未封裝項目」，指定本資料夾。在 RO 放置仙境分頁進入角色，再從 Chrome 工具列開啟擴充。點擊圖示會直接開啟獨立懸浮視窗，即使切換瀏覽器分頁也會保留該視窗內的輸入與試算結果。更新角色時，會讀取原本的遊戲分頁。

選定怪物、攻擊方式和模擬時間。結果顯示有效傷害的平均 DPS、首殺時間、期末 SP、各攻擊的傷害占比及技能時間。擊殺時間僅平均已完成首殺的樣本，旁邊會顯示有幾次成功擊殺。

模擬會讀取目前角色的公開遊戲快照，在本機執行 16 次，用各自固定的亂數種子。每次從快照的 HP、SP、已學技能、裝備、道具與可讀取的狀態開始。怪物倒下後立即放入同種滿血目標，保留角色的技能冷卻及剩餘補給。指定技能模式在該技能無法施放時依引擎規則普攻。掛機模式沿用戰鬥施放、換裝及補給條件；宏指令、回城補給、找怪、掉落及隊友不納入。已在身上的隊友 Buff 會倒數。角色內部戰鬥狀態從新遭遇起算。

「模擬怪物反擊並計算承傷」預設關閉。勾選後，怪物可以普攻、施技和打斷詠唱。雙方在可交戰距離開始，角色倒下後結束該次模擬。承傷量計算實際扣除的 HP，包含怪物攻擊、技能與狀態持續傷害。介面顯示承傷量、每秒承傷、存活次數、期末 HP、承傷來源及第 1 次模擬的對戰時間軸。擴充只透過 GET 讀取遊戲 API。

## 對應原始碼及重建

`engine.js` 以本資料夾的 `simulator.ts` 和 [RO 放置仙境公開客戶端原始碼 df6277909](https://ro-idle.app/source/ro-idle-client-src-df6277909.tar.gz) 建置，並用 `instrument-engine.py` 記錄引擎實際扣除的 HP。執行 `bash build.sh` 可重新下載對應原始碼並產生相同模擬引擎。引擎依 GPL-3.0 授權，授權與上游聲明見同資料夾的 LICENSE、THIRD_PARTY_NOTICES、ASSET_NOTICES。

「角色 Buff 與怪物狀態」預設不套用遊戲快照中的 Buff，也不自補。可勾選快照 Buff，或手動加入指定等級和持續秒數的 Buff 與怪物狀態。角色能力欄會先顯示無起始 Buff 的面板，選入效果後即時顯示數值與差額。怪物狀態視為已施加，不額外擲成功率；每隻新目標會帶著同一組設定開場。0 秒代表不自然到期，像天使之怒或冰凍仍會依引擎規則被攻擊消耗或解除。可關閉自補 Buff 避免掛機技能或 Buff 道具改變比較條件。

歌舞 Buff 可輸入演奏者在施放當下的總素質，以及操控樂器或練習舞蹈等級。演奏者素質預填 90，歌舞技能和演奏被動技能均預填最高等級。布萊奇之詩讀 DEX 和 INT，其他歌舞依所選效果顯示相關欄位。結果會列出套用的歌舞加成。伊登的蘋果每 6 秒回復一次 HP，模擬假設演奏者在設定時段持續支援。

對戰紀錄列出第一個模擬樣本的角色動作、怪物普攻及施技、狀態變化、承傷及 HP。開啟怪物反擊可看到怪物主動出招。

角色 Buff 及怪物狀態用勾選清單設定，可依名稱或代碼篩選。勾選後會展開等級、時間及歌舞需要的素質欄位。篩選會保留已勾選的效果。
