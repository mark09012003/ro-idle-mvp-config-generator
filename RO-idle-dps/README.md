# RO 放置仙境 · 單怪 DPS 試算

同時支援**獨立網頁版**（手機／電腦皆可使用）與 **Chrome 擴充模式**。

## 網頁版與自訂角色配點工作室（免裝擴充、手機／電腦皆可用）

直接透過 GitHub Pages 或任何靜態網頁伺服器開啟本資料夾的 `index.html`（例如 `RO-idle-dps/`），採響應式分頁工作室介面（電腦雙欄側邊即時能力面板＋手機可展開能力摘要條，支援淺色／深色模式切換）：

- **獨立自訂角色（免匯入即可使用）**：可自由建立自訂角色，設定**轉生次數**（0 轉一般職業／1 轉進階職業）、**41 種職業**、**Base／Job 等級**、騎乘大嘴鳥／攜帶獵鷹，並內建與遊戲一致的**六圍屬性配點器**（含點數花費計算與自由配點模式）及**完整技能樹配點器**（自動補齊前置技能、任務技能免點數、掛機施放開關）。
- **方式一：書籤小工具（跨分頁一鍵傳送）** — 點擊「匯入遊戲角色」→「複製書籤程式碼」建立書籤（電腦可直接拖曳按鈕到書籤列）。在 `https://ro-idle.app` 遊戲分頁點選該書籤，就會自動讀取目前角色快照並傳送到 DPS 試算網頁（優先透過 `postMessage` 傳送，手機瀏覽器隔離時自動退回壓縮網址 Hash 或剪貼簿）。
- **方式二：貼上 JSON／匯入檔案** — 開啟 `https://ro-idle.app/api/characters` 查角色 ID，再開啟 `/api/characters/<ID>?deferCatchup=1` 全選複製並貼上，或匯入本工具匯出的完整配點 JSON 檔。
- **本機配點管理** — 可將多個自訂配點或匯入角色（含裝備／精煉／卡片覆寫）儲存在瀏覽器 `localStorage`，隨時切換、匯出或刪除。

## 自訂裝備／精煉／卡片

載入角色後可展開「自訂裝備／精煉／卡片」面板：

- 支援編輯全部 10 個裝備部位（頭上、頭中、頭下、武器、副手、鎧甲、披肩、鞋子、飾品 1、飾品 2），並可從角色背包快速套用已有裝備。
- 支援依名稱、ID 或說明搜尋裝備（預設只顯示目前職業與等級可裝備項目，可取消勾選檢視全部裝備），可卸下裝備或單一／全部還原。
- 可精煉裝備支援調整 `+0`～`+10`；有洞裝備支援依部位篩選對應卡片（刺客雙刀左手自動對應武器卡），並提供多洞一鍵套用插槽 1。
- 變更裝備、精煉或卡片時，「角色能力」面板會即時顯示變更前後數值與增減，且已自訂部位不會被掛機自動換裝規則覆蓋。

## Chrome 擴充模式

到 `chrome://extensions` 開啟「開發人員模式」，選「載入未封裝項目」，指定本資料夾。在 RO 放置仙境分頁進入角色，再從 Chrome 工具列開啟擴充。點擊圖示會直接開啟獨立懸浮視窗，即使切換瀏覽器分頁也會保留該視窗內的輸入與試算結果。更新角色時，會讀取原本的遊戲分頁。

選定怪物、攻擊方式和模擬時間。開啟視窗時預設使用目前掛機施放設定，起始箭矢沿用裝備與自動補箭。結果顯示有效傷害的平均 DPS、首殺時間、期末 SP、各攻擊的傷害占比及技能時間。擊殺時間僅平均已完成首殺的樣本，旁邊會顯示有幾次成功擊殺。

模擬會讀取目前角色的公開遊戲快照，在本機執行 16 次，用各自固定的亂數種子。每次從快照的 HP、SP、已學技能、裝備、道具與可讀取的狀態開始。怪物倒下後立即放入同種滿血目標，保留角色的技能冷卻及剩餘補給。指定技能模式在該技能無法施放時依引擎規則普攻。掛機模式沿用戰鬥施放、換裝及補給條件；宏指令、回城補給、找怪、掉落及隊友不納入。已在身上的隊友 Buff 會倒數。角色內部戰鬥狀態從新遭遇起算。

「模擬怪物反擊並計算承傷」預設關閉。勾選後，怪物可以普攻、施技和打斷詠唱。雙方在可交戰距離開始，角色倒下後結束該次模擬。承傷量計算實際扣除的 HP，包含怪物攻擊、技能與狀態持續傷害。介面顯示承傷量、每秒承傷、存活次數、期末 HP、承傷來源及第 1 次模擬的對戰時間軸。擴充只透過 GET 讀取遊戲 API。

## 對應原始碼及重建

`engine.js` 以本資料夾的 `simulator.ts` 和 [RO 放置仙境公開客戶端原始碼 8af00cc61](https://ro-idle.app/source/ro-idle-client-src-8af00cc61.tar.gz) 建置，並用 `instrument-engine.py` 記錄引擎實際扣除的 HP。執行 `bash build.sh` 可重新下載對應原始碼並產生相同模擬引擎。引擎依 GPL-3.0 授權，授權與上游聲明見同資料夾的 LICENSE、THIRD_PARTY_NOTICES、ASSET_NOTICES。

「角色 Buff 與怪物狀態」預設不套用遊戲快照中的 Buff，也不自補。可勾選快照 Buff，或手動加入指定等級和持續秒數的 Buff 與怪物狀態。角色能力欄會先顯示無起始 Buff 的面板，選入效果後即時顯示數值與差額。怪物狀態視為已施加，不額外擲成功率；每隻新目標會帶著同一組設定開場。0 秒代表不自然到期，像天使之怒或冰凍仍會依引擎規則被攻擊消耗或解除。可關閉自補 Buff 避免掛機技能或 Buff 道具改變比較條件。

歌舞 Buff 可輸入演奏者在施放當下的總素質，以及操控樂器或練習舞蹈等級。演奏者素質預填 90，歌舞技能和演奏被動技能均預填最高等級。布萊奇之詩讀 DEX 和 INT，其他歌舞依所選效果顯示相關欄位。結果會列出套用的歌舞加成。伊登的蘋果每 6 秒回復一次 HP，模擬假設演奏者在設定時段持續支援。

對戰紀錄列出第一個模擬樣本的角色動作、怪物普攻及施技、狀態變化、承傷及 HP。開啟怪物反擊可看到怪物主動出招。

角色 Buff 及怪物狀態用勾選清單設定，可依名稱或代碼篩選。勾選後會展開等級、時間及歌舞需要的素質欄位。篩選會保留已勾選的效果。

角色六圍顯示為「基本素質＋額外加成」，額外值包含職業、裝備、卡片、被動技能與選入的 Buff。可展開「試算裝備與箭矢」核對目前裝備的精煉值及卡片，以及箭矢種類、ATK、屬性、目前堆疊數量與起始普攻屬性。戰鬥模擬會消耗背包複本中的箭矢。

勾選「無限 SP」後，模擬會在戰鬥動作之間補滿角色當下的最大 SP。技能仍依遊戲規則計算耗魔、詠唱、延遲與冷卻，並正常消耗箭矢和施法材料。

弓、樂器或鞭子的箭矢欄是空的時候，試算會按遊戲邏輯從背包補箭，先選自動補貨設定的箭種，再選數量最多的一疊。這個選擇只發生在本機模擬。

「起始箭矢」預設會用選定怪物比對自動換裝規則，再採目前裝備或背包補箭。也可手動指定箭種，背包沒有時使用 1,000 支模擬庫存。手動指定會取代掛機換裝規則的箭矢部分，其餘部位照常換裝。模擬仍會消耗箭矢。

勾選「角色免傷，怪物照常施技」會同步啟用怪物反擊。怪物普攻、技能及會持續扣血的異常狀態不扣角色 HP，怪物仍會施技、施加狀態和召喚。範圍技能依遊戲引擎命中範圍內的召喚物，傷害會另計，也會列出包含召喚物的合計 DPS。

單次傷害列出一般命中及爆擊的原始傷害區間，方便與遊戲日誌比較。超過怪物剩餘 HP 的部分會另外標示，DPS 和傷害占比採用有效傷害。
