# RO 放置仙境 · 單怪 DPS 試算

這是獨立的 Chrome 擴充。到 `chrome://extensions` 開啟「開發人員模式」，選「載入未封裝項目」，指定本資料夾。在 RO 放置仙境分頁進入角色，再從 Chrome 工具列開啟擴充。

選定怪物、攻擊方式和模擬時間。結果顯示有效傷害的平均 DPS、首殺時間、期末 SP、各攻擊的傷害占比及技能時間。擊殺時間僅平均已完成首殺的樣本，旁邊會顯示有幾次成功擊殺。

模擬會讀取目前角色的公開遊戲快照，在本機執行 16 次，用各自固定的亂數種子。每次從快照的 HP、SP、已學技能、裝備、道具與可讀取的狀態開始。怪物倒下後立即放入同種滿血目標，保留角色的技能冷卻及剩餘補給。指定技能模式在該技能無法施放時依引擎規則普攻。掛機模式沿用戰鬥施放、換裝及補給條件；宏指令、回城補給、找怪、掉落、隊友及怪物主動反擊不納入。已在身上的隊友 Buff 會倒數。角色內部戰鬥狀態從新遭遇起算。擴充只透過 GET 讀取遊戲 API。

## 對應原始碼及重建

`engine.js` 以本資料夾的 `simulator.ts` 和 [RO 放置仙境公開客戶端原始碼 df6277909](https://ro-idle.app/source/ro-idle-client-src-df6277909.tar.gz) 建置。執行 `bash build.sh` 可重新下載對應原始碼並產生相同模擬引擎。引擎依 GPL-3.0 授權，授權與上游聲明見同資料夾的 LICENSE、THIRD_PARTY_NOTICES、ASSET_NOTICES。
