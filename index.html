地圖與巡迴路線

勾選地圖並加入巡迴。清單由上往下執行，可自由調整順序、重複加入同一張地圖（系統會自動切分到不同配置檔依序輪巡），或展開地圖修改個別怪物。

怪物目標怎麼選

加入地圖時，每張只會預先勾選 MVP。要把 Boss 或小怪加入目標，請展開該地圖的「怪物設定」，勾選想加入的怪物。

刷懷錶範例
  1. 將地圖篩選切到「所有地圖」，在搜尋欄輸入「狂暴大腳熊」。
  2. 勾選「普隆德拉迷宮森林 2樓」和「龍之城王陵」，再按「加入巡迴」。
  3. 在巡迴清單中分別展開這兩張地圖的「怪物設定」，各自勾選「狂暴大腳熊」。

勾選地圖後，按「加入巡迴」。

    掉落物篩選（選填）

    直接選擇每種道具回城時要不處理、出售或存倉。套用後會一起匯出到巡迴配置。

    匯入原有道具設定（選填）

    有遊戲匯出的道具設定 JSON 才需要匯入，也可以直接在下方編輯。

    自訂巨集（選填）

    用表單加入製作聖水、箭矢、自動施放技能等巨集。這些巨集會套用到每一份配置。

    自訂巨集 0 條；每份配置最多 10 條。

    進階：直接編輯巨集 JSON

    可貼上遊戲匯出的巨集陣列。修改後按「套用 JSON」。含換圖或切換配置步驟的巨集會由巡迴產生器重建。

    分享／匯入完整配置（選填）

    打包整頁所有設定（隊伍人數、帶隊職業、Buff、三種角色規則、巡迴路線、掉落物篩選與自訂巨集），方便備份或傳給隊友。若只想分享地圖順序，請用上方的「分享／匯入巡迴路線」。

    操作預覽與下載

    展開每份配置，核對等待、離圖和配置切換順序。下載後按配置名稱在遊戲中儲存，從 01 開始。

    三種角色共用路線與隊伍人數，並各自套用自己的進階設定。
